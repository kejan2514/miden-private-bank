MIDEN BANK MODEL

How this maps to the tutorial

01

Account component

The bank component owns programmable storage and defines the account-facing banking logic.

02

Deposit note

A deposit arrives as a note carrying assets and the data needed for the bank-side operation.

03

Withdrawal request

A separate note expresses the request and invokes the bank's withdrawal path.

04

Output note

The transaction can produce a new note that carries withdrawn assets back to the intended recipient.
